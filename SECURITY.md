# Security

simpleota handles firmware signing keys and API tokens, so please report
anything that could expose them, let someone sign or ship firmware, or
bypass a check privately by email to support@simpleota.com rather than in a
public issue.

Include the version (`simpleota --version`), your OS, and steps to
reproduce. You will get a reply within a few working days, and a fix is
released before the details are made public.

Only the latest release is supported.
